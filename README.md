
# 🚀 Global AI Hub - All-in-One AI & Automation Platform

منصة عالمية متكاملة لتقديم خدمات الذكاء الاصطناعي، الأتمتة، العقود القانونية، والوساطة الرقمية بأسعار تنافسية ودعم كامل للدفع الفوري عبر USDT (TRC20).

---

### ✨ مميزات المنصة (Key Features)
* 🎨 **واجهة حديثة ومتجاوبة:** مصممة باستخدام React و Tailwind CSS بتصميم داكن فاخر يعمل بنجاح على الهواتف والأجهزة اللوحية.
* 💳 **نافذة دفع كريبتو (USDT Checkout):** إمكانية نسخ محفظتك وإدخال رقم المعاملة (TxID) مباشرة عبر شبكتي TRC20.
* 🤖 **أقسام متنوعة للخدمات:**
  * **AI & Media Hub:** توليد سيناريوهات الفيديوهات القصيرة، خطط المحتوى، وأوامر الصور.
  * **Business & B2B:** أتمتة الردود على العملاء وتلخيص ملفات PDF و Excel الضخمة.
  * **Legal & Contracts:** صياغة عقود العمل المستقل (NDA) وسياسات الخصوصية.
  * **Crypto Escrow:** خدمات الوساطة المالية لحماية حقوق المستقلين والشركات.

---

### 🛠️ البنية التقنية (Tech Stack)
* **Frontend:** React + Tailwind CSS
* **Hosting:** Vercel / GitHub
* **Automation Backend:** n8n Self-Hosted
* **Database:** Supabase
* **Verification:** TronScan Blockchain API
